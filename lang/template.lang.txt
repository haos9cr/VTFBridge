# VTFBridge language file template (all strings in English).
#
# Two ways to use a translation:
#  a) Built into the plug-in: put the file into the project's lang\ folder
#     (e.g. lang\pl.lang) and rebuild. Check it with: python tools/check_lang.py
#  b) Without rebuilding: put it into the VTFBridge_lang folder next to VTFBridge.8bi.
#     A file there with the same language.code as a built-in language only
#     overrides the strings it contains.
#
# Set language.name (shown in the list) and language.code, translate the values.
# Keys you delete fall back to English. Encoding: UTF-8, extension: .lang.
# \n = line break. {w}, {error}, ... are placeholders and must stay as they are.

tip.point_sample = No smoothing between pixels: a crisp, pixelated look (pixel art, some UI).
tip.trilinear = Trilinear filtering: smooth blending between mipmap levels.
tip.anisotropic = Anisotropic filtering: keeps the texture sharp when seen at a steep angle.
tip.clamp_s = Do not repeat the texture horizontally: edge pixels are stretched instead.
tip.clamp_t = Do not repeat the texture vertically: edge pixels are stretched instead.
tip.clamp_u = Do not repeat along the depth (volume textures only).
tip.no_mipmap = The engine uses only the full-size image. Typical for UI and HUD textures.
tip.no_lod = Always load the full resolution, ignoring the texture quality setting.\nTypical for UI and HUD textures.
tip.normal_map = The texture is a normal map. Mipmaps are renormalized so that the bumps\ndo not flatten out in the distance; gamma-correct filtering is not applied.
tip.ssbump = Self-shadowing bump map (for example made with height2ssbump).\nUse it with "$ssbump" "1" in the material.
tip.hint_dxt5 = Used for skybox textures: helps to avoid visible seams at the edges.
tip.srgb = Marks the texture as sRGB. Rarely needed: most Source games ignore it.
tip.no_debug_override = Excludes the texture from the engine's debug texture overrides.
tip.single_copy = The engine keeps only one copy of this texture in memory.
tip.vertex_texture = Texture read by vertex shaders. Rarely needed.
tip.border = Clamp to a border colour instead of the edge pixels. Rarely needed.
tip.tiling = For textures that repeat (walls, floors, terrain): resizing and mipmaps blend\nthe left edge with the right one and the top with the bottom, so no seam appears.\nLeave it off for decals, sprites, UI and anything with a transparent border:\notherwise pixels from one edge bleed into the opposite edge of the mipmaps.\nClamp S / Clamp T turn it off for their direction.
tip.dxt_quality = How the DXT colours (and DXT5 alpha) of every 4x4 block are chosen.\nFast (stb_dxt): as in VTF Export 1.0 / VTFBridge 1.1.\nHigh / Best (icbc by Ignacio Castano): third-party encoder; on very smooth\ngradients it can leave visible steps. Best also gives a better DXT5 alpha.\nVTFBridge: Accurate (default): stb_dxt + VTFBridge's own refinement -\nthe smoothest gradients, equally accurate on every graphics card, better DXT5 alpha.\nVTFBridge: Perceptual: like Accurate, but errors count the way the eye sees them\n(green > red > blue); not for masks or data. Normal maps always use Accurate.
tip.alpha = Where the alpha of the texture comes from:\nLayer transparency - the checkerboard areas, like in a PNG.\nChannel - an alpha channel from the Channels panel (a mask, e.g. for\n$basealphaenvmapmask or $selfillum), while the image itself stays opaque.\nNone - the texture is saved without alpha.\nAuto uses the first alpha channel if there is one, otherwise the transparency.\nFor animation frames, Auto and transparency use each layer's own transparency.
tip.sharpen_alpha = Sharpen the alpha channel of the mipmaps as well, so cut-outs ($alphatest),\nfences, foliage and thin details do not fade out in the distance.\nLeave it off for soft transparency gradients.
tip.sharpen = Sharpens every mipmap below the full-size image, so details stay readable\nin the distance (like the sharpening of the old NVIDIA tools in VTFEdit).\n0% = off. Too much gives bright halos on edges; check it in the preview.
tip.preview = Shows the texture exactly as it will be saved: every mipmap compressed and decoded back,\nwith the accuracy against a reference (the uncompressed mips or your own image).\nViews: result, reference, split, difference, the whole mip chain; tiling, zoom, Auto level.\nFilters, sharpness and DXT quality can be changed right in the preview.
tip.vmt = Also writes a material next to the .vtf. $basetexture is the path after the\n"materials" folder. Alpha adds $alphatest (cut-out) or $translucent (soft),\nseveral frames add the AnimatedTexture proxy.\nAn existing .vmt is never overwritten. Not available for normal maps.
tip.shader = VertexLitGeneric: models\nLightmappedGeneric: world brushes\nUnlitGeneric: sprites, UI, no lighting
